# TBCarryGlobalConfig
````json lines
{
    "version": "2",
    "isInitialized": 1,
    "enablePackActionOnBots": 1, // 0=off 1=on If you have bots and it should not be possible to pack them when they are dead set this value to 0,
    "autoPackPlayerOnDeath": 0, // 0=off 1=on Automatically pack players into a body bag after death,
    "autoPackBotsOnDeath": 0, // 0=off 1=on Also automatically pack AI bots after death,
    "autoPackDelayInSeconds": 5, // Minimum delay after death before automatic packing,
    "deleteDeadBodyAfterAutoPack": 0 // 0=off 1=on Delete the dead player body after automatic packing
}
````
