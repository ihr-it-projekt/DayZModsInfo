# Global configurations for TB Mods

Here you will find all global configurations shared across TB Mods.

## Global Configs

These configuration files are located in your server profile directory under `YourServerProfilesFolder\TBMods\Config\Global`:

- [**TBLib Administration Menu**](AdminMenu.md): Overview of the in-game administration menu.
- [**AdminConfig.json**](AdminConfig.md): Server administrator IDs and permission flags.
- [**CurrencyConfig.json**](CurrencyConfig.md): Multi-currency definitions, banking integrations (LBMaster ATM, DC Banking) and item values.
- [**Premium.md**](Premium.md): Premium coins and API documentation.
- [**PremiumConfig.json**](PremiumConfig.md): Configuration for the premium system and API.
- [**Tip4ServApiConfig.json**](Tip4ServApiConfig.md): Tip4Serv API integration.
- [**TBKeyBindsConfig.json**](TBKeyBindsConfig.md): Keybindings for TB mods.
- [**VehicleSpawnConfig.json**](VehicleSpawnConfig.md): Safe vehicle spawn configurations.
- [**Logger.json**](Logger.md): Global logging options (Discord / CSV).
- [**NPCGearConfig.json**](NPCGearConfig.md): Gear loadouts for mod NPCs.
- [**Reputation System**](/GlobalConfigs/ReputationSystem/Index.html): Shared reputation integration across mods.
