# How to discover Mod Conflicts

## Guide

### General
- create a test server with minimal setup (your Admin Tool) and the mod you have problems with
- start the server and join it
- check if you have still the same problem as with full setup.
- if there are no errors, go to step `add mods`


### Add Mods
- add more mods (approx 50 % of remaining mods, if you do this step after remove step, add 25% of remaining mods)
- check if the problem is still there
- if problem does not occur, repeat this step
- if problem occurs, go to step `remove mods`

### Remove Mods
- remove 50% of mods you added in last step (if you do this step after add step, remove 25% of remaining mods)
- if problem does not occur, go to `add mods`
- if problem occurs, repeat this step


### Final Step
- If you have found the mod that causes the problem, create a ticket at https://discord.gg/kGjN6gJy3m
- name your problem and the conflicting mod.
- add all inforamtions you have, e.g. Videos, Screenshots and your last.log files.
